# Source Preservation Policy

The portfolio wrapper was created without changing the original project artifacts.

## Preserved byte-for-byte

- all three Jupyter notebooks;
- `volatility_utils.py`;
- both raw CSV datasets;
- the original repository `README.md`; and
- the final PDF report.

No source code, notebook cell, output, metadata, comment, model definition, parameter, path, metric, report page, or dataset value was edited.

## Added separately

The root documentation, extracted preview images, `.gitignore`, dependency list, verification record, and checksum manifest were created around the original work. Images under `assets/` were decoded from PNG outputs already embedded in the unchanged notebooks.

## Integrity check

`ORIGINAL_FILE_MANIFEST.tsv` records the original archive path, portfolio path, byte size, and SHA-256 digest for each preserved artifact.
