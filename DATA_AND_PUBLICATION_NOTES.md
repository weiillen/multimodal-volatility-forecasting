# Data and Publication Notes

Review these points before publishing the repository.

## Team attribution and personal information

The original repository README and final report contain contributor names, role descriptions, institutional affiliations, and email addresses. They are preserved unchanged for authenticity, but all collaborators should be comfortable with public redistribution.

## Financial-news text

`news_data_raw.csv` contains full article text and source URLs, including material associated with third-party publishers. The uploaded archive does not contain a dataset license or redistribution permission. Publicly hosting the complete CSV may therefore require a rights review.

A lower-risk public portfolio version could retain the code and documentation while replacing the raw article text with:

- a small legally shareable sample;
- a data-acquisition description;
- document identifiers and URLs only; or
- instructions for users to obtain the source data themselves.

No such replacement was made here because the preservation rule requires keeping the uploaded data unchanged.

## Price data

`price_data_raw.csv` contains OHLCV data, but the supplied files do not identify its provider or license. Confirm the source and redistribution terms before public release.

## Financial-use disclaimer

The project is an academic forecasting experiment. It is not validated for trading, portfolio allocation, regulatory reporting, or production risk management.
